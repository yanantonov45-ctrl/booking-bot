# 💈 Booking Bot — Telegram-бот записи к мастеру

Бот-администратор для барбершопа, салона, студии маникюра или любого бизнеса с записью по времени. Клиент записывается сам за минуту, администратор получает уведомление.

## Возможности

**Для клиента**
- выбор услуги → дня → свободного времени (занятые и прошедшие слоты скрыты);
- имя и телефон (кнопкой «Отправить номер» или вручную, с проверкой формата);
- подтверждение записи с карточкой;
- «Мои записи» — просмотр и отмена в один клик;
- услуги с ценами, контакты.

**Для администратора** (`/admin`)
- мгновенное уведомление о новой записи со ссылкой на клиента;
- отмена записи одной кнопкой — клиент получает сообщение;
- расписание на сегодня / завтра / 7 дней с ожидаемой выручкой.

**Надёжность**
- защита от двойной записи на один слот на уровне БД (уникальный индекс);
- учёт часового пояса;
- кнопки «Назад» и «Отмена» на каждом шаге.

## Стек
Python 3.10+, aiogram 3, aiosqlite (SQLite), FSM, uv.

## Запуск
Нужен [uv](https://docs.astral.sh/uv/):
```bash
uv sync                # создаст .venv и поставит зависимости из uv.lock
cp .env.example .env   # вставьте токен и свой Telegram ID
uv run main.py
```
Без uv: `pip install -r requirements.txt`, затем `python main.py`.

## Настройка
Услуги, часы работы, рабочие дни и контакты — в `config.py`.

## Структура
```
main.py          — запуск
config.py        — настройки, услуги, расписание
database.py      — работа с SQLite
slots.py         — расчёт свободного времени
keyboards.py     — клавиатуры
texts.py         — шаблоны сообщений
handlers/user.py — сценарий клиента
handlers/admin.py— панель администратора
```
